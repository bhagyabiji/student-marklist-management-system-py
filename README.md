
# Student Marks Management System

A beginner-friendly Python project to manage student details and marks through a simple command-line interface.

## Features

- Add student records
- Enter marks for five subjects
- Calculate total marks and percentage
- Assign grades automatically
- View all student records
- Search students by roll number
- Delete student records
- Save data using JSON file handling
- Validate marks and prevent duplicate roll numbers

## Technologies Used

- Python 3
- JSON for data storage
- Built-in Python modules

## Subjects

- English, Mathematics, Computer Science, Physics, Chemistry

## How to Run

1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   python main.py

## Data Storage

Student records are stored in `students.json`.
This file is created automatically when a student is added.
